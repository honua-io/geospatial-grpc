# @honua/geospatial-grpc

Generated protobuf-es messages and service descriptors for the stable
`geospatial.v1` protocol. The package version matches the schema tag and
conformance fixture version.

```bash
npm install @honua/geospatial-grpc@1.0.0
```

```typescript
import { FeatureService } from "@honua/geospatial-grpc/geospatial/v1/feature_service_pb.js";
```

Use the exported service descriptors with `@connectrpc/connect` and the
transport appropriate for your runtime.
